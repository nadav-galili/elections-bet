## AI-Powered Israeli Elections Bet System

## Problem

The israeil elections are coming Up and there is no system That enables groups of friends to make friendly wagers or bets on the outcome of this election.

## Solution

Build a system that will help manage Groups of friends that could place bets or wager on each party's election outcome and compare to real results.
Each user could place the number of mandates that He thinks a party will have and will compare them to the real election results.
The closer the user is to the real results, the more points he gets.

## Features

- A user can log in and join or create groups of friends.
- Scoring is counted for each group. Also there is a global leaderboard.
- After signing in, the user will see a list of the groups he joined or created and will be able to join or create new groups and when Entering into a group, he will see his picks.
  User can't see other users' picks from this group Until the real results are concluded .
- User will have one place or one screen to make his picks. This pick Will be on each group he creates or joins.
- Each group should have a Group admin that will be able to send invites to new users and delete users from this group. Other regular users won't have this option to delete, only to invite new users.
- Regular users should see which of the other users in this group already made picks but not show the picks' values.
